We built a website that helps children from age 6 till 12 to start programming. 
Their task is to move the robot to the star of the maze, with using the least amount of tiles as possible.

To make the game more suitable to different ages / skills of the kids there is a easy and advanced mode implemented into the game.


In the easy code the task is to move the robot to the star with the provided moving blocks for the robot.

Our website addresses the SDG 4 - Quality Education because, 


Within our agegroup there is not a real excludement. It does assume the learner can see and has the congnetic abilities to solve a problem with movements. 
The Language is English.
Computer is needed. 
There is a internet network needed because the site is online. 
There is no prior knowledge needed to move the robot, it is a simple click and go!
