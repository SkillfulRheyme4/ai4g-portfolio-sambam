We built a one-page educational game for children aged 6 to 12 that introduces basic programming concepts through a maze challenge. The goal is to guide a robot to the star by using movement blocks such as move forward, turn left, and turn right. Players must solve the maze using as few blocks as possible, which encourages logical thinking, planning, and problem-solving.

The game has two difficulty modes: Easy and Advanced, so children with different skill levels can still participate and be challenged appropriately. The interface is simple, colorful, and cartoon-like to make it fun and approachable for young learners.
SDG 4 — Quality Education

Our website supports SDG 4: Quality Education because it makes early programming education more accessible and engaging. It helps children learn computational thinking in a playful way, without requiring any prior coding knowledge. By offering a simple, interactive experience, the app lowers the barrier to entry for children who are just starting to learn how to think algorithmically.
