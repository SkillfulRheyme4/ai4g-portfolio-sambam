# Robot Maze Quest

We built a one-page educational game for users aged 6 to ~13 that introduces basic programming concepts through a maze challenge. The goal is to guide a robot to the star using movement blocks such as move forward, turn left, and turn right. Users must solve the maze using as few blocks as possible, which encourages logical thinking, planning, and problem-solving.

The game has three difficulty modes — Easy, Advanced, and Expert — that don't just get harder, they introduce new programming concepts at each stage. Easy teaches sequencing: placing movement blocks in the right order. Advanced adds repeat blocks and gives users the option to write their own code, so they learn to compress repeated steps into a loop instead of stacking the same block over and over. Expert introduces if-statements, so users learn to make the robot respond to conditions in the maze rather than following one fixed path. Together, these three tiers walk users through the three foundational building blocks of computational thinking, so a user who reaches Expert has had hands-on practice with the core ideas that make up programming, not just a harder maze. Because users of different skill levels can enter at the tier that suits them, the game stays challenging and appropriate whether it's a user's first time or their fifth.

The interface is simple, colorful, and cartoon-like to make it fun and approachable for young users, and every maze is randomly generated, so the game can be replayed many times without repeating a level.

Our website supports SDG 4: Quality Education because it makes early programming education more accessible and engaging. It helps users learn computational thinking in a playful, ungraded way, without requiring any prior coding knowledge, and it lowers the barrier to entry for users who are just starting to learn how to think algorithmically — while the tiered structure means the same tool keeps teaching new concepts as a user's skills grow, rather than being a one-off activity.

The website does not require prior programming knowledge and is designed as a simple click-and-play experience, so users can start immediately: no installation, sign-up, or account is needed. It does, however, assume that the user can see the screen, understands basic English or Dutch, and has access to a computer or tablet with an internet connection. Because of this, some users with visual impairments, limited device access, or reading difficulties may currently be excluded — a limitation we address further in our ethical reflection.
